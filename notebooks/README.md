# Notebooks

This directory contains Jupyter notebooks for exploration and experimentation.

## Planned Notebooks

- `01_data_exploration.ipynb` — Explore the text-to-SVG dataset
- `02_model_inference.ipynb` — Test model inference interactively
- `03_svg_analysis.ipynb` — Analyze generated SVGs
- `04_eval_results.ipynb` — Visualize evaluation results

## Setup

Make sure the conda environment is activated and the package is installed:

```bash
conda activate svg-agentic-slm
pip install -e .
```
